Case study

Thrift Books

Campus marketplace for buying and selling second-hand books.

web Jul-Sep 2023

Problem

Students needed a practical way to list, browse and trade used books with reliable data for listings and transactions.

Solution

Built a dynamic web site with structured database administration for listings, users and buy/sell flows.

Result

A usable campus marketplace demonstrating end-to-end web and database delivery.

Thrift Books was built to make second-hand book trading simpler for students. I worked across website design and database administration so users could browse listings, manage posts and complete buy/sell flows through a dynamic web experience.

  • End-to-end website design for buying and selling used books
  • Database administration for listings, users and transactions
  • Dynamic frontend and backend integration
  • Focused on a practical campus marketplace use case

Tech stack

HTML5 CSS3 JavaScript MySQL SQLite REST API
