Thrift Books

Jul–Sep 2023

Thrift Books was built to make second-hand book trading simpler for students. I worked across website design and database administration so users could browse listings, manage posts and complete buy/sell flows through a dynamic full-stack experience.

  • End-to-end website design for buying and selling used books
  • Database administration for listings, users and transactions
  • Dynamic frontend and backend integration
  • Focused on a practical campus marketplace use case

MOBILE College project

Swaad Sathi

May–Jul

Swaad Sathi connects people living in rental housing — who often lack time to cook — with home kitchens and cloud-kitchen style providers. I worked on frontend design and development in Flutter and React Native and explored AI chatbot integration with manual training for guided assistance.

  • Mobile-first experience for renters and home kitchens
  • Frontend development with Flutter and React Native
  • AI chatbot integration for guided user help
  • Solves a real lifestyle problem around daily meals
Flutter React Native AI Chatbot

Gym App

Sep–Oct

A personal-use fitness app built to track my own workouts and activity. I implemented the frontend in Flutter and used SQLite for local data storage so progress could be saved offline without a heavy backend.

  • Flutter frontend for activity tracking
  • SQLite local database for saving progress
  • Built for personal daily use and iteration
  • Practical experience with offline-first mobile data
